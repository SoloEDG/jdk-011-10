# 方屿 Blockhaven

需要 Node.js 22。

安装：`npm ci`

本地启动：`npm run dev`，打开终端显示的地址。

Docker 启动：`docker compose up --build`，打开 http://localhost:8111。

## 图片浮雕

右侧「图片浮雕」面板可导入截图或图片，自动生成有立体层次的方块浮雕：

- 按亮度生成高度（可选暗部凸起），用现有材质近似颜色；透明背景保留为空洞
- 支持拖动裁切、调整宽度与层次、选择贴地或水平基准面
- 确认前在场景中显示半透明预览与逐材质预算，冲突位置标红
- 大图转换可取消；库存不足时可保留轮廓自动精简或用近似色替代
- 确认时重新检查遮挡、角色与库存，任一不满足则保留预览，绝不只落一半
